## CMIN2 是什么，为什么值得专门搜这个词

CMIN2，全称 China Mobile International Network 2，是中国移动国际在 2022 年下半年推出的精品骨干线路，官方定位是对标电信 CN2 GIA 的移动版高速路。

普通 CMI（China Mobile International）是移动出口的常规通道，CMIN2 是在 CMI 基础上专门划出来做了优先级保障的子线路。名字只差两个字母，实际体验差距明显，尤其是晚高峰时段——CMIN2 的优化优先队列会让数据包绕开拥挤的公网出口，这是和普通线路最本质的区别。

讲真，前两年 CMIN2 的商家很少，大部分打这个旗号的都在玩文字游戏。DMIT 的 LAX.EB 系列是目前这条线路里真正拿得出路由测试来对号入座的产品之一。
